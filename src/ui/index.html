3 Подключение к файлам

Нужно личное защищённое подключение между ChatGPT и этим компьютером. Оно называется туннелем. Для нового компьютера создайте отдельное подключение.

  1. ID туннеля — шаг 1 из 2

    На сайте OpenAI Platform войдите в свой аккаунт или завершите регистрацию. В разделе Tunnels создайте туннель и свяжите его со своим пространством ChatGPT.

    Нажмите Copy tunnel ID рядом с созданным туннелем. Можно выделить ID, начинающийся с tunnel_, и скопировать: Command+C на Mac или Ctrl+C в Windows.

    Вернитесь в Web Pilot. Он примет ID и откроет шаг API key. Если шаг не переключился, нажмите «Вставить ID туннеля». В открывшемся системном окне вставьте ID: Command+V на Mac / Ctrl+V в Windows, затем подтвердите ввод.

  2. Личный API key — шаг 2 из 2

    ID уже сохранён для этого шага. Теперь создайте секретный ключ OpenAI: он начинается с sk- и разрешает подключение к вашему туннелю.

    На открывшейся странице выберите ту же организацию, что и для туннеля. Нажмите Create new secret key («Создать новый секретный ключ»), задайте имя, например Web Pilot, выберите проект, если сайт его запрашивает, и подтвердите создание ключа.

    В появившемся окне нажмите Copy и скопируйте весь секретный ключ sk-…. Здесь нужен сам ключ, а не его имя или ID туннеля. Если полное значение уже недоступно, создайте новый ключ.

    Вернитесь в Web Pilot: он получит скопированный ключ и начнёт подключение. Если этого не произошло, нажмите «Ввести API key» ниже и вставьте ключ в открывшееся защищённое поле: Command+V на Mac / Ctrl+V в Windows. Подтвердите ввод. ID туннеля повторно вводить не нужно.

    Для работы вашему аккаунту нужны права Tunnels: Read + Use в организации туннеля. Если доступа нет, их выдаёт владелец организации или администратор.

Ключ сохраняется в защищённом хранилище этого компьютера. Ввод открывается отдельным системным окном.

Нет раздела Tunnels или доступа?

Проверьте выбранную организацию OpenAI. Для создания нужны права Tunnels Read + Manage, для использования — Read + Use. Доступ к developer mode в ChatGPT проверяется отдельно; в управляемом пространстве его выдаёт администратор.

4 Подключение в ChatGPT

Туннель готов. Теперь добавьте подключение к этому компьютеру в ChatGPT — оно не появляется автоматически.

  1. Откройте Plugins в основном сайдбаре ChatGPT. Список Plugins в настройках показывает уже установленные подключения.
  2. Нажмите «+», укажите имя Codex App Server Local Mac и описание «Доступ к проектам на этом компьютере».
  3. Выберите Connection: Tunnel и туннель этого компьютера. Для этого локального подключения выберите No authentication и создайте подключение.
  4. Дождитесь списка инструментов. Если он не появился, проверьте выбранный туннель и его связь с вашим пространством ChatGPT.

Если подключение к этому компьютеру уже есть, повторно добавлять его не нужно. Проверьте его туннель и список инструментов; одно название не подтверждает доступ.

Для этой Windows используйте подключение «Codex App Server Local Windows» и туннель этого компьютера. Если раньше вы уже создали «Codex Local Windows MCP» с этим же туннелем, новое подключение не нужно: откройте прежнее и обновите в нём список инструментов (Refresh). Подключение Mac остаётся отдельным. Windows-подключение нужно проверить, даже если служба туннеля уже работает.

Разрешения MCP

После создания подключения откройте в ChatGPT Settings → Plugins → ваше подключение → Permissions. Выберите имя, которое вы задали для этого компьютера.

  • Always ask — спрашивать перед чтением и изменениями.
  • Allow read actions — читать без подтверждения, спрашивать перед изменениями.
  • Allow low-risk actions — автоматически разрешать действия низкого риска; действия с чувствительными данными могут быть отклонены. Это режим по умолчанию.
  • Allow all actions — читать и выполнять действия без повторных запросов подтверждения.

Для удобной работы агента без постоянных подтверждений можно выбрать Allow all actions. Агент сможет в том числе изменять файлы через это MCP без отдельного вопроса. Режим выбираете вы; изменить его можно здесь же в любой момент.

Эта настройка управляет подтверждениями. Права самого подключения и ограничения ChatGPT сохраняются.

Нет кнопки «+» или подключение не работает?

В ChatGPT откройте Settings → Security and login → Developer mode. Доступ зависит от настроек аккаунта и пространства. После изменения подключения обновите его список инструментов через Refresh.

5 Первый проект

После добавления подключения создайте новый проект или выберите существующую папку. В новом чате откройте меню инструментов и добавьте подключение к этому компьютеру.

Попросите агента прочитать и изменить тестовый файл в папке проекта. Если он видит только подключение другого компьютера, выберите нужное подключение и начните новый чат с ним.

Мы проверим выбранную папку и покажем, что нужно добавить для работы с проектом.

Готовность туннеля и передача контекста ещё не подтверждают доступ агента к файлам. Результат проверяется по сохранённому файлу.
