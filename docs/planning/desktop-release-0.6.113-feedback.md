## D-001 — AutoPlan не запускает только что опубликованный план

- **Статус:** Открыто; повторная проверка ожидается.
- **Область:** десктоп, Chat, AutoPlan, публикация нового sequential-плана.
- **Условия:** пользовательская кнопка AutoPlan уже была включена (`ON`). Новый план `chat-session-rotation-20261011` согласован через Review и опубликован; Workflow Kit показывает `ACTIVE`, следующая задача `T001`, завершено `0/12`.
- **Действие:** агент публикует план, затем завершает свой ответ пользователю.
- **Ожидаемое поведение:** без участия пользователя Web Pilot отправляет в этот Chat ровно одно «Продолжай» с актуальной следующей задачей `T001`; выполнение плана начинается автоматически. Переход OFF→ON не требуется.
- **Фактическое поведение (сообщение пользователя):** после публикации плана и окончания ответа агента автоматическое «Продолжай» не пришло; выполнение не стартовало, хотя кнопка AutoPlan была включена.
- **Предстоящая проверка пользователя:** вручную выключить AutoPlan и включить снова; проверить, появится ли «Продолжай» и начнётся ли `T001`. Исход пока не получен.
- **Важные ограничения диагностики:** состояние кнопки и отсутствие отправки известны из наблюдения пользователя; внутренние события AutoPlan/DOM, причина отказа и результат OFF→ON ещё не исследованы. Не считать исправленным без проверки реального сценария **ON до публикации → публикация → idle → одно Continue**.
- **Критерий закрытия:** воспроизводимость исследована; сценарий исправлен при необходимости и покрыт регрессионным тестом вместе с пользовательской проверкой. Сохранение исходного плана, отсутствие второго Send и работа после Recovery обязательны.
